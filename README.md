# RJLib: Core Modding Library

_A unified library of PowerShell and xEdit Pascal/Delphi modules required by RJ's modding tools._

## 📝 What is RJLib?

**RJLib** is a comprehensive framework and resource library. It contains a collection of shared PowerShell (.psm1/.ps1) and xEdit Pascal/Delphi (.pas) scripts that power my advanced modding utilities (such as ACE and BMAT).
**For Standard Users:** If you were directed here by another one of my tools, you simply need to download and install this library so that the tool can function.
**For Mod Authors & Tool Makers:** This is an open modder's resource. You are free to utilize these shared libraries, procedures, and functions to accelerate the development of your own xEdit scripts and PowerShell utilities.

## ⚙️ Requirements

For RJLib to function correctly (and for the tools that rely on it to work), the following prerequisites are required:
* **Target Game:** Fallout 4 (Currently the only supported game framework).
* **xEdit:** Version 4.1.5 or newer.
* **PowerShell:** Windows PowerShell v5.x (No additional installation required, this version is built into Windows).
* **Creation Kit:** Specifically the base Papyrus scripts. CK can be installed from Steam.
* **Additional Tools:** BSArch, Champollion, and Caprica.

## 📥 Installation

Installation is strictly manual. Because these are core scripts for xEdit and PowerShell, they must be placed in a specific location, not installed via a standard mod manager like MO2/Vortex.
* Download the latest RJLib .zip archive from [NexusMods](https://www.nexusmods.com/games/fallout4/mods/104749).
* Extract the contents directly into your root xEdit folder (the folder containing FO4Edit.exe or FO4Edit64.exe).
* If prompted, allow the files to merge with your existing Edit Scripts directory.

## 🛠️ Modder's Resource: Included Modules

I plan to continuously update this library with new functionality. Currently, the modules include advanced procedures and functions for:
* **Plugin Management:** FO4 plugin FormID calculation and modification.
* **Record Editing:** Advanced plugin parsing, and automated record creation, modification, and removal.
* **Archive Handling:** BA2 and ZIP archive extraction and automated repackaging.
* **File Operations:** Deep file searching, creation, and modification via PowerShell.
* **Data Parsing:** Native parsers for TXT, JSON, YAML, and INI configuration files.
* **Papyrus Automation:** Automated Papyrus script decompilation and recompilation.
* **System Utilities:** Advanced log management, log rotation, and data reporting.
